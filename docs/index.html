Purpose

What PYPE is for

PYPE helps researchers scan many phenotypes for associations, organize the resulting signals, visualize them, and follow selected findings with Mendelian randomization.

A PheWAS can produce thousands of regression results from one set of predictors. The statistical model is only one part of the work. Results also need consistent metadata, multiple-testing thresholds, plots that remain readable across many phenotype groups, and downstream analyses that use the same allele conventions.

PYPE keeps those steps in one dataframe-based Python workflow. Genotype dosages, risk scores, biomarkers, or other numeric phenotypes can be predictors. Outcomes and covariates remain ordinary pandas columns, so the analysis can fit into an existing notebook or research pipeline.

Motivation

Why we built it

Investigator-driven analyses

Public association browsers cannot cover every cohort subset, imaging sample, omics panel, derived phenotype, or custom hypothesis.

One result model

PheWAS, metadata joins, significance correction, plotting, and MR use explicit dataframe schemas rather than unrelated scripts.

Auditable MR

The implemented estimators were compared directly with the TwoSampleMR and MR-PRESSO R references.

Reproducible outputs

The public MR portion of the original paper can be rerun from the cited summary-statistic sources.

Workflow

Typical analysis

Prepare data

Align phenotype, predictor, and covariate rows by sample index.

Run PheWAS

Estimate each requested predictor-outcome association with complete cases.

Add context

Join readable phenotype descriptions and categories, then create plots.

Follow up

Harmonize exposure and outcome summary statistics and run selected MR estimators.

Use cases

When PYPE fits

  • Testing a small set of variants or scores against many numeric phenotypes.
  • Running PheWAS within a selected cohort subset or custom study population.
  • Comparing phenotype groups with Manhattan and enrichment plots.
  • Following PheWAS findings with two-sample MR from local summary statistics.
  • Checking Python MR results against the published R implementations.
PYPE focuses on statistical analysis after data preparation. Cohort extraction, genotype file conversion, phenotype construction, and study-specific quality control remain upstream.
