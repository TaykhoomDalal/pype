Overview

PheWAS

Regress genotype or phenotype predictors against many outcomes with optional covariates.

Plots

Create Manhattan, volcano, and category enrichment plots directly from result dataframes.

Mendelian randomization

Run IVW, MR-Egger, median, mode, and MR-PRESSO methods after allele harmonization.

Install

Install the current development version directly from GitHub:

python -m pip install "git+https://github.com/TaykhoomDalal/pype.git@development"

For an editable source checkout:

git clone --branch development https://github.com/TaykhoomDalal/pype.git
cd pype
python -m pip install -e .

Install the optional BioThings annotation clients when needed:

python -m pip install ".[annotations]"

Run a PheWAS

import pandas as pd
import pype

phenotypes = pd.DataFrame({
    "trait_a": [1.2, 2.0, 1.5, 3.1],
    "trait_b": [0.0, 1.0, 0.0, 1.0],
    "age": [50, 61, 47, 70],
})

predictors = pd.DataFrame({
    "variant_1": [0, 1, 1, 2],
})

results = pype.phenome_wide_association(
    phenotypes,
    predictors,
    outcomes=["trait_a", "trait_b"],
    covariates=["age"],
    min_samples=3,
)
The phenotype and predictor dataframes must use the same sample index. Each regression uses rows with complete predictor, outcome, and covariate data.

Input and output formats

Phenotype dataframe

LayoutRequirement
RowsSamples or participants.
IndexMust match the predictor dataframe index exactly.
ColumnsNumeric outcome phenotypes and optional numeric covariates.
Missing valuesAllowed. PYPE uses complete cases separately for each regression.

Predictor dataframe

LayoutRequirement
RowsThe same samples and index as the phenotype dataframe.
ColumnsOne or more numeric predictors. These may be genotype dosages, scores, or phenotypes.
Genotype codingProvide dosages such as 0, 1, and 2 as numeric dataframe columns.

PheWAS result dataframe

ColumnDescription
Data_FieldOutcome phenotype name.
Independent_VarPredictor name.
SamplesComplete cases divided by total input samples.
-log(p)Negative base-10 logarithm of the p-value.
p-valRegression p-value.
betaPredictor effect estimate.
std_errorStandard error of the effect estimate.

Phenotype metadata

The plotting functions require a category for each outcome. Join a metadata dataframe or delimited file with add_phenotype_metadata.

ColumnDescription
Data_FieldField identifier matching the PheWAS result.
DescriptionOptional readable label used for annotations.
CategoryGroup used on Manhattan and enrichment plots.

MR summary statistics

ColumnRequiredDescription
rsIDYesVariant identifier.
CHRYesChromosome. Values X and Y are accepted.
Effect_AlleleYesAllele associated with BETA.
Non_Effect_AlleleRecommendedOther allele used for reliable harmonization.
BETAYesEffect estimate.
SEYesStandard error.
PYesP-value.
NOptionalSample size. Used to choose among duplicate rows.

Plotting

import pandas as pd
import pype
from pype.plotting import category_enrichment, manhattan, volcano

metadata = pd.DataFrame({
    "Data_Field": ["trait_a", "trait_b"],
    "Description": ["Trait A", "Trait B"],
    "Category": ["Measurements", "Diagnoses"],
})

results = pype.add_phenotype_metadata(results, metadata)
manhattan(results, "manhattan.png")
category_enrichment(results, "category_enrichment.png")
volcano(results, "volcano.png")

Manhattan and volcano functions also write tab-separated files containing significant results beside the image files.

Mendelian randomization

results, diagnostics = pype.mendelian_randomization(
    exposure,
    outcome,
    exposure_name="exposure_trait",
    outcome_name="outcome_trait",
    methods=("ivw", "egger", "weighted_median"),
    seed=0,
)

Use methods="all" to run every method. PYPE aligns matching alleles, flips reversed effects, accepts strand complements, and removes incompatible or ambiguous palindromic variants.

The implemented estimates were checked directly against the TwoSampleMR R source and MR-PRESSO reference implementation.

Gene annotation

A gene interval file is used only to find genes near a variant. The genome assembly of the variants and the gene file must match.

ColumnDescription
#chromChromosome, such as chr1.
cdsStartGene coding start coordinate.
cdsEndGene coding end coordinate.
name2Gene symbol.

UCSC RefSeq and GENCODE interval exports can be used. Choose GRCh37/hg19 or GRCh38 to match the variant coordinates.

Public API

pype.phenome_wide_association

Run covariate-adjusted PheWAS regressions from aligned dataframes.

pype.add_phenotype_metadata

Join descriptions and categories to PheWAS results.

pype.mendelian_randomization

Harmonize variants and run selected MR methods.

pype.plotting

Create Manhattan, volcano, and category enrichment plots.
